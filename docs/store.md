# Chrome Web Store preparation

**Name:** Loreweave  
**Short description:** Local-first AI browser assistant and story studio. Bring your own keys.  
**Category:** Productivity (or Writing / Workflow)

## Longer description

Loreweave is an AI side panel for the web and a studio for long-form fiction. Summarize a page, rewrite a selection, continue a chapter, keep character memory, and check continuity — using API keys you already have.

You own your writing. Nothing is published for you. Page text is sent only when you ask.

## Feature list (store)

- Side panel AI on ordinary websites
- Selection actions for explain / rewrite / story craft
- Story Studio, characters, world bible, timeline
- BYOK for major model APIs and local Ollama
- Notes and reusable prompts
- Optional supporter links (Patreon)

## Do not claim

- Perfect style cloning of living authors
- Guaranteed plot-hole detection
- Exact dollar costs unless the provider returns them
- Background scraping of the internet

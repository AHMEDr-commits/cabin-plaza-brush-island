# Manual Chrome checklist

1. Load unpacked `extension/` (Developer mode).
2. Toolbar action opens the side panel.
3. Ctrl+Shift+Space opens the panel.
4. Select text on example.com → right-click Loreweave → Explain (requires a key).
5. Providers: add a dummy key, confirm mask, reveal, delete.
6. Test key against a real key (expect pong or a vendor error, never a raw key in the error).
7. Read this page: title and excerpt appear; disable network and confirm notes still save.
8. Story Studio continue with sample chapter.
9. Save to notes from context menu; Memory lists it.
10. Support links open the four Patreon URLs.
11. chrome://extensions → Errors: none after the above.
12. PDF in Chrome's viewer: selection actions may work; full-file extract may not — that is expected.

Web studio: open the preview, send a prompt without a key (demo or a clear error), add a key, switch modes without losing the chapter, command palette Ctrl/⌘+K, mobile width does not overflow.
